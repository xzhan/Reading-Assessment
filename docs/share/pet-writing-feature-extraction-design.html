第一版 ML Scorer 输入设计

把一篇作文变成模型能学习的数字

Feature extraction 是 PET Writing 监督学习闭环里的翻译层。它把学生作文、题目信息和用时转换成一组可解释的数字特征，让模型学习这些特征和老师评分之间的关系。

核心理解

Feature Vector
模型真正看到的数字输入，也就是监督学习里的 X。
Teacher Labels
老师人工复核后的四个维度分，也就是模型要学习预测的 y。
Goal
先做可解释 baseline，等 gold data 变多后再升级更复杂模型。

Data Flow

一条作文不会直接进入第一版回归模型。它会先被拆解成结构化信号，再被转成纯数字特征。

Step 01

Student Essay

学生提交作文原文，例如 PET email response。

Step 02

Prompt Metadata

读取 task type、目标字数、题目内容点。

Step 03

Feature Extraction

统计长度、覆盖率、连接词、词汇多样性等信号。

Step 04

Feature Vector

把所有信号转换成模型可读取的数字。

Step 05

ML Scorer

预测四个维度分，再加总成 overall score。

Three Output Layers

同一条作文会产出三层信息。它们分别服务于报告解释、人工审阅和模型训练。

Signals

人能读懂的作文表现信号。它们既可以显示在报告里，也可以进入模型训练。

word_count task_coverage lexical_diversity connector_density

Evidence

解释信号背后的证据。它帮助老师和学生理解为什么系统这样判断。

content_hits missing_content_points repeated_words

Feature Vector

最终给模型使用的数字对象。第一版 Ridge / LightGBM / CatBoost 都可以吃这个结构。

X numeric only trainable

Example Conversion

左边是学生作文，右边是同一篇作文被转换后的特征向量。注意：模型看到的是右边这些数字。

这个例子内容点覆盖很好，所以 task_coverage = 1.0。但它只有 43 个词，不在 PET 目标字数范围，所以 within_target_word_count = 0.0。这正是特征提取的价值：它能同时保留不同维度的证据，而不是只给一个笼统判断。

Training Connection

Feature extraction 的最终意义，是让人工复核产生的 gold data 可以进入监督学习训练。

X Model Input

feature_vector 是模型输入。它包含作文长度、内容覆盖、语法风险、词汇多样性、连接词密度等数字。 

{
  "word_count": 43.0,
  "task_coverage": 1.0,
  "grammar_error_rate": 0.0,
  "lexical_diversity": 0.86
}

y Teacher Labels

teacher-reviewed labels 是标准答案。模型训练时学习如何从 X 预测 y。 

{
  "task_achievement": 5,
  "organization_coherence": 4,
  "grammar_control": 4,
  "lexical_range_accuracy": 4
}
重要边界：老师评分不是 feature。老师评分是训练标签。模型部署后，面对新作文时只能看到 feature_vector，然后预测四个维度分。
